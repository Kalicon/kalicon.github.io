# Kalicon Amorim — Portfólio Interativo & Code Engine

Repositório da página web pessoal e portfólio interativo de **Kalicon Amorim**, hospedado no GitHub Pages em **[https://kalicon.github.io](https://kalicon.github.io)**.

---

## Funcionalidades e Destaques

- **Scroll-Driven Code Engine:** Editor interativo integrado que digita e renderiza trechos de código em tempo real sincronizados com a rolagem de cada projeto.
- **Retro Snake Arcade (Easter Egg):** Jogo clássico da cobrinha implementado em Canvas HTML5, temático com blocos de commits do GitHub, placar de pontuação, recorde persistido em `localStorage` e suporte a teclado e controles touch para mobile.
- **Showcase de Projetos Reais:** Vitrine interativa com links de produção e código fonte para **Claravellas** (E-Commerce de Velas), **RHUB** (Suíte CLT em PWA), **Calculadora Hospitalar SES-SP** e **IntraHub**.
- **Design System & Performance:** Interface dark mode moderna com glassmorphism, tipografia com fontes Google Fonts (Inter e Fira Code), animações fluidas e zero dependências externas pesadas (100% Vanilla HTML5, CSS3 e JavaScript).
