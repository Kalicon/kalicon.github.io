01 / E-Commerce

Claravellas — E-Commerce de Velas Personalizadas

Plataforma de comércio eletrônico de alto padrão para velas aromáticas e presentes artesanais. Desenvolvida para alta velocidade de carregamento, checkout seguro e inteligência de vendas.

  • Integração de pagamentos com Stripe (Checkout seguro e webhooks).
  • Persistência e catálogo em MongoDB Atlas.
  • Painel administrativo de controle de pedidos e estoque (BI).

02 / PWA & CLT

RHUB — Suíte de Cálculos Trabalhistas

Solução web desenvolvida como desafio acadêmico para automatizar regras complexas da legislação brasileira (CLT) e simular custos de contratação CLT vs. PJ com ponto de equilíbrio.

  • 100% offline via Progressive Web App (Service Worker).
  • 14 testes unitários automatizados no Vitest com 100% de aprovação.
  • Exportação de planilhas Excel estruturadas com SheetJS e impressão executiva.

03 / Saúde Pública (SES-SP)

Calculadora de Escalas Hospitalares (HMLMB)

Ferramenta criada para apoio às chefias e equipes do Hospital Maternidade Leonor Mendes de Barros (UGA IV), resolvendo o desafio matemático de plantões fracionados.

  • Algoritmo de compensação cíclica de plantões que zera o saldo no semestre.
  • Dimensionamento assistencial de enfermagem baseado na Resolução COFEN 743/2024.
  • Orientador de limites de plantão extra segundo a Lei Complementar Estadual 1176/2012.

04 / Enterprise Backend

IntraHub — Portal Corporativo & Intranet

Demonstrativo de arquitetura corporativa em Java 17 e Spring Boot 3, projetado para centralização operacional, trilha de auditoria e alta rastreabilidade.

  • Controle de acesso granular baseado em papéis (RBAC) com Spring Security 6.
  • Replicação automatizada de escalas departamentais em lote.
  • Documentação integrada de API via OpenAPI 3 / Swagger UI.
